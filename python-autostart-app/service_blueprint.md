# サービスブループリント
## ログイン時自動録画システム（ミニマムMVP）

---

## 登場人物

| ロール | 説明 |
|--------|------|
| ユーザー | 測定対象のPC利用者 |
| SE（運用担当） | Slackで失敗を検知し対応する担当者 |
| システム | Python スクリプト群（daemon / recorder / rerun） |
| 外部サービス | Zapier / Slack |

## このプロダクトへのタッチポイント一覧

| # | タッチポイント | チャネル | 対象者 | 発生条件 |
|---|--------------|---------|--------|---------|
| 1 | **PCログイン** | OS ログイン画面 | ユーザー | 毎日のログイン時 |
| 2 | **スリープ復帰** | OS（画面ロック解除） | ユーザー | スリープから復帰時 |
| 3 | **録画完了（サイレント）** | なし（バックグラウンド） | — | 録画成功時（通知なし） |
| 4 | **Slack失敗通知** | Slack チャンネル | SE・ユーザー | 録画失敗時のみ |
| 5 | **SEからの連絡** | Slack DM / チャンネル | ユーザー | 失敗検知後 |
| 6 | **再実行リンク** | Slack → ブラウザ | ユーザー | 失敗後・SE案内後 |
| 7 | **再実行完了画面** | ブラウザ（localhost） | ユーザー | リンククリック時 |

---

## ユーザーに必要な操作（ジャーニー整理）

### 通常時（成功パス）
```
ログイン → （自動録画・操作不要） → 完了
```
**ユーザー操作: 0回**

### 失敗時（リカバリーパス）
```
ログイン → 録画失敗 → Slack通知受信 → SEからの連絡確認
→ Slackの再実行リンクをクリック → ブラウザで完了確認
```
**ユーザー操作: 1回（リンクのクリックのみ）**

---

## 制約・前提条件

| 項目 | 内容 |
|------|------|
| カメラ権限 | 初回のみユーザーが手動で許可が必要 |
| Python環境 | 対象PCに Python + opencv-python + requests が必要 |
| ネットワーク | 失敗通知にインターネット接続が必要（Zapier経由） |
| 再実行リンク | ユーザーが自分のPC上のブラウザで開く必要がある |
| 録画保存先 | Mac: ~/Movies/recordings/ / Win: ~/Videos/recordings/ |
